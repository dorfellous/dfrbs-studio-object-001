# DFRBS Studio — Object 001

Responsive campaign storefront prototype for DFRBS Studio's biomorphic eyewear collection.

## Stack

- React 19
- Vite 6
- Phosphor Icons
- Locally bundled open-source fonts

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run test:sites
```

The production client is emitted to `dist/client`. The project also retains the Product Design worker and hosting metadata needed for an optional future Sites deployment.

## Current scope

- Responsive desktop and mobile campaign page
- Interactive BLACK / PEARL / HEAT colorway selector
- Campaign, object details, collection navigation, and product drawer
- Local bag interaction with no payment, inventory, or persistence backend

Product photographs and campaign imagery are supplied DFRBS Studio assets. Do not redistribute them independently of the project.
